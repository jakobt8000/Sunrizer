# SUNRIZE

Dreamy pad synth (VST3 + AU, macOS) by **REZONANZA**. Same sound engine as the browser prototype:
10 chord sounds, sun knob (filter, click = start/stop), TONE, WEATHER, WIDTH, BIRDS, BLOOM, AFTERGLOW,
DRIFT, DUST, LIGHT, DROPS and OUTPUT. MIDI notes also start it and transpose the chord (C4 = original pitch).

Every push builds the plugin with `.github/workflows/build-mac.yml`. Download `SUNRIZE-mac` from the
Actions run, unzip and double-click `install.command` (or follow `INSTALL.txt`).
